# Saguari Gastro House — Landing Page

Site institucional de conversão para o restaurante Saguari Gastro House
(QS 310, Samambaia Sul — Brasília/DF).

## Como visualizar
Abra o arquivo `index.html` no navegador. Não precisa de build, servidor
nem instalação — é HTML, CSS e JavaScript puro.

## Estrutura
```
index.html            → a página inteira
assets/css/style.css  → identidade visual (verde garrafa + dourado)
assets/js/main.js     → animações, menu mobile, carregamento de fotos
assets/img/           → fotos (ver LEIA-ME.md com os nomes exigidos)
```

## O que ainda precisa ser preenchido
1. **Fotos** — veja `assets/img/LEIA-ME.md`. A página funciona sem elas.
2. ~~Depoimentos~~ ✅ — 4 avaliações reais do Google já publicadas na página
   (Pâmella Ribeiro, Warley Borges, Ycaro Rodrigues, Vivian Costa). São trechos
   fiéis; as reticências marcam onde o texto original continua.
3. **Cardápio** — o botão "Ver cardápio completo" aponta hoje para o Linktree.
   Trocar por um PDF/página própria quando houver.
4. **Link de reserva** — todos os CTAs vão para o WhatsApp (61) 99877-5943.
   Se houver sistema de reservas, trocar os `href`.

## Publicar
Site 100% estático. Basta subir a pasta em qualquer hospedagem
(Vercel, Netlify, Hostinger, GitHub Pages) ou arrastar a pasta em vercel.com.
